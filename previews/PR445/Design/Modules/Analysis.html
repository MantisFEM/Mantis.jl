Analysis ​

The analysis module is, currently, one of the smallest module in Mantis. It provides a few functions to compute the - and -norms either globally or per element.

Mantis.Analysis.L2_norm Function
julia
L2_norm(
    u::Forms.AbstractForm{manifold_dim},
    dΩ::Quadrature.AbstractGlobalQuadratureRule{manifold_dim},
) where {manifold_dim}

Compute the -norm of the given form u using the given quadrature dΩ. See also L2_norm_per_element.
