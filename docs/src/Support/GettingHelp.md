# Getting Help

If you need help with anything `Mantis`-related then the best way of getting in touch with
us is by using the [Discussions page](https://github.com/MantisFEM/Mantis.jl/discussions).
Here you can ask questions, provide feedback, or help brainstorm ideas, for example.

If, however, you already know that you want to specifically submit a bug report, request a
feature, or want to contribute, you can find more information in the following pages:

 1. [Submitting a bug report.](./SubmitBugReport.md)
 2. [Requesting a new feature.](./FeatureRequest.md)
 3. [Contributing.](./Contributing.md)
